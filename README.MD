FEATURES APPLICAZIONE DA DIVIDERE:

1) registrazione sicurezza

2) "KONRAD" -> creazione profilo utente (fra i dati dell'utente apparirà la media delle reviews e la
lista completa di tutte le sue reviews), richiedere i dati del profilo utente per ID

3) "GIUSEPPE" -> pubblicazione annunci + stato annuncio + preferenze

4) "FRANCESCO" -> ricerca degli annunci per categoria e nel caso range di prezzo

5) inserimento oggetti, ricercarli, cancellarli

6) messaggistica privata tra clienti (inviare messaggio ad utente, vedere tutti i propri messaggi
                                   opzionalmente solo quelli non letti, rispondere al messagio, cancellare messaggio)

7) admin possono creare, modificare, disattivare categorie

8) "DOMENICO" -> creazione offerta per annuncio, visualizzazione offerte ricevute e inviate
approvazione offerta e possibilità di fare la controfferta.

9) possibilità di lasciare una recenzione a scambio concluso, e al termine può rilasciare
una valutazione dell'esito

10) "MANUEL" -> l'utente può lanciare una segnalazione (report) nel caso il prodotto non rispettasse 
le linee guida o non fosse conforme alle regolamentazioni (sarà poi l'admin a prendere
in carico la segnalazione, approvandole o rifiutandole)
